# N-grammer

Простая система автодополнения текста: вы печатаете письмо — она подсказывает следующее слово или дописывает недописанное. Работает как подсказки в почте или поисковой строке, но вместо нейросети внутри обычная n-граммная модель, посчитанная по 517 тысячам реальных писем.

## Как этим пользоваться

```bash
# 1. Обучить модель (один раз, ~2 минуты)
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/train_and_save.py --csv ../emails.csv

# 2. Запустить бекенд
uvicorn app.main:app --port 8000

# 3. Запустить фронтенд (в новой вкладке терминала)
cd ../frontend
npm install
npm run dev
```

Открыть **http://localhost:5173** — это страница написания письма:

- лучшая подсказка показывается серым прямо в тексте (как в Gmail);
- варианты под полем — альтернативы, клик мышью тоже применяет;
- `Tab` — принять подсказку, `↑`/`↓` — выбрать другую, `Esc` — убрать.

│   │   ├── cleaner.py        — очистка текста: убрать адреса, ссылки, мусор
│   │   └── main.py           — FastAPI: эндпоинт /suggest, к нему ходит фронтенд
│   ├── scripts/
│   │   └── train_and_save.py — читает письма, считает частоты, сохраняет в data/
│   ├── data/                 — обученная статистика (создаётся скриптом)
│   └── tests/test_model.py   — проверка модели: python tests/test_model.py

└── frontend/                 — страница письма (Vue 3 + Vite)

## Как это работает

1. **Один раз** скрипт читает письма и считает: какие слова встречаются и как часто, а также какое слово шло после каждой пары слов. Результат складывается в `backend/data/`.
2. Сервер держит эту статистику в памяти. Когда вы печатаете, фронтенд присылает текущий текст на `/suggest` и получает варианты продолжения.
3. Логика подсказки:
   - печатаете **недописанное слово** («пожалуйста найди сп») → ищем в словаре слова на «сп» и предлагаем самое частое;
   - напечатали слово и **пробел** → смотрим в статистике, какое слово обычно идёт после последних двух («спасибо тебе» → «за»), и жадно продолжаем цепочку до трёх слов.

## Если что-то не работает

- `data/` пустая → не запустили обучение (шаг 1), либо запускали не из папки `backend/`;
- подсказок нет → проверьте бекенд: `curl http://localhost:8000/health`;
- порт занят → поменяйте 8000 на другой и поправьте прокси в `frontend/vite.config.js`.
